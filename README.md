# 🏥 The Virtual ICU: Real-Time Remote Patient Monitoring (RPM)
## End-to-End IoT Streaming Pipeline on Databricks

### 🚀 Overview
In modern healthcare, minutes matter. This project simulates a Remote Patient Monitoring (RPM) system—often called a "Virtual ICU"—designed to ingest, process, and analyze high-frequency vital signs from medical IoT sensors.

By leveraging Databricks Community Edition, this pipeline demonstrates a production-grade Medallion Architecture that transforms raw, noisy sensor pings into actionable clinical alerts. It solves the critical engineering challenge of processing "dirty" medical data at scale while maintaining strict schema enforcement and biological logic.
